# Application Logs

For debugging purposes, we may ask you to send us your OpenGolfSim Desktop application logs. See below for how to locate your log file.


### Windows

On Windows the log file can be found in your user's `AppData` folder:

```
%USERPROFILE%\AppData\Roaming\opengolfsim-desktop\logs\main.log
```

### MacOS

On MacOS the log file can be found in your user's `Logs` folder:

```
~/Library/Logs/opengolfsim-desktop/main.log 
```

{: .note }
> You should be able to copy+paste the above string into your file explorer address bar.
