## Generate Terrain

You can create a completely fictional course terrain by selecting Generate in the Course Area and then clicking the Generate Terrain button.

1. If you selected Generate in the Course Area section, you should see a **Generate Terrain** button in the **Terrain** section in the sidebar.
2. Choose if you want **Flat** or **Random** terrain to be generated.
3. Once it's finished generating you should be able to select <a href="../editing">**Edit Terrain**</a> to start shaping it.
